# Sthira

A short contemplative 2D platformer created for the Sadhanapada AI Hackathon 2026.

The player takes the role of a seeker travelling toward a mountain shrine. Rather than explaining its ideas through conventional instruction, Sthira uses exploration, stillness, observation and interaction to let the player encounter them through gameplay.

## Play

**Browser version:** https://mariusheider.github.io/the-still-path/

No installation is required.

## Controls

- **A / Left Arrow** — Walk left
- **D / Right Arrow** — Walk right
- **Space / W / Up Arrow** — Jump
- **E** — Sit / interact

## Run locally

1. Install **Godot 4.6.1**.
2. Clone or download this repository.
3. Open `project.godot` in Godot.
4. Run the project with **F6/F5** or the editor's Run Project button.
